# Security policy

Please report suspected vulnerabilities privately by email to
shekhawatsamvardhan@gmail.com, not as public issues. Include a description,
the affected commit or version, and steps to reproduce.

You can expect an acknowledgement within seven days. Please allow time for a
fix before any public disclosure.

A reproducible cross-platform output mismatch (different bytes for the same
input and configuration on two supported platforms) is a correctness bug
rather than a security issue; report it as a public issue unless it has
security implications.
